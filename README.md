## First start
- Windows: "Windows protected your PC" → More info → Run anyway.
- Mac: right-click the app → Open → Open.

## Features
- Rename your AI
- Make your own icon or upload an image
- Small, Medium, Large, Full screen or custom size
- Snap to a corner or drag it anywhere (remembered)
- Keep on top, see-through window, accent colour
- Ctrl + Shift + Space shows and hides it
